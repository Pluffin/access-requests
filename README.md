# 🔑 Access requests

My trading projects are private. To get read access to one of them, open a request:

**[→ Request access](../../issues/new?template=request-access.yml)**

| Project | What it is |
|---|---|
| **Stratos** | Opening Range Breakout (ORB) bot for TopstepX funded futures accounts (MNQ) |
| **Autopilot** | 24/7 AI-assisted trading system for MyFundedPerps funded accounts |

## How it works

1. Open a request and pick the project. You need to be signed in to GitHub.
2. I review it and add your GitHub account as a collaborator.
3. You'll get an invitation email from GitHub. Accept it to see the repository.
4. I close your request once access is granted.

Requests are public: only your GitHub username, Discord username and the project you picked are visible. Don't post emails, API keys or account details here.
